# NexoCode

Independent fork of [opencode](https://github.com/anomalyco/opencode) — the open source AI coding agent.

## Purpose

NexoCode is a community fork exploring architectural improvements to the upstream codebase, including:
- XDG Base Directory specification compliance fixes
- Plugin system hardening (error isolation, capability manifests)
- External plugin isolation via sandboxing
- General cleanup and simplification

## Status

Heavily work in progress. This is not a stable release.
